# 🎬 Indian Movie Analytics Dashboard

## 📌 Project Overview
The **Indian Movie Analytics Dashboard** is an interactive Power BI dashboard designed to analyze movie trends, user preferences, and rating patterns across different genres.

The dashboard provides insights into:
- Movie genre distribution
- Average movie ratings
- User demographics
- Gender-based rating analysis
- Interactive filtering and reporting

This project demonstrates data visualization, dashboard design, KPI tracking, and Power BI reporting skills.

# 📈 Visualizations Used

### 1. Average Rating by Genre & Gender
- Line chart comparing average ratings given by male and female users across genres.
- Helps identify audience preferences by genre.

### 2. Total Movies by Genres
- Horizontal bar chart showing the number of movies available in each genre.
- Highlights the most popular genres in the dataset.

### 3. User Gender Distribution
- Displays the distribution of male and female users.

### 4. Average Rating Card
- Shows the overall average movie rating in a clear KPI format.

# 📖 How to Use

1. Open the Power BI `.pbix` file.
2. Use the slicers on the left panel to filter dashboard data.
3. Interact with charts and visuals for detailed insights.
4. Hover over visuals to view additional information.
